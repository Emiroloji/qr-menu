## "Bitti sayılır" doğrulaması

Kaynaktaki ölçüt: "Boş proje açılıyor, veritabanına bağlanıyor." Vercel yerine yerelde doğrulandı:

- `npm run typecheck` ✅, `npm run lint` ✅, `npm run format:check` ✅, `npm run build` ✅
- `npm run dev` ile ana sayfa açıldı (HTTP 200, "QR Menü").
- `POST /api/auth/sign-up/email` ile Better Auth üzerinden bir deneme kullanıcısı oluşturuldu ve `User` tablosunda göründü. Uçtan uca veritabanı bağlantısı çalışıyor. Deneme kaydı sonra silindi.

## Kararlar ve notlar

- **Prisma sürümü:** npm'deki "latest" etiketi 8.0.0-rc.15, yani bir aday sürüm. Bu yüzden son kararlı sürüm olan **7.10.0** seçildi.
- **Better Auth tabloları (User, Session, Account, Verification) şemaya elle yazıldı.** Better Auth'un şema oluşturma aracı (`auth` CLI) Node 22 istiyor, bilgisayarda Node 20.19 var. Tablolar Better Auth'un standart şemasıyla aynı. `User`'daki `role` ve `businessId` alanları Faz 1.1'de eklenecek.
- **Paketler:** Motion, sharp, qrcode, next-intl, Zod gibi paketler henüz kurulmadı. İlgili adımda kurulacak (KURALLAR: "İhtiyaç yoksa yazılmaz").
- **Temizlik:** create-next-app'in örnek sayfası ve SVG'leri kaldırıldı. `lang="tr"` ayarlandı.
- **Otomatik Prisma:** `postinstall` betiği `prisma generate` çalıştırıyor. Üretilen istemci (`lib/generated/prisma`) git'e girmiyor.
- **Güvenlik uyarısı:** `npm audit`, Prisma CLI'nin içindeki `mysql2` paketi için 4 yüksek seviyeli uyarı veriyor. Bu yalnızca geliştirme aracında, MySQL kullanmıyoruz. Önerilen `--force` düzeltmesi Prisma'yı 6'ya düşürdüğü için uygulanmadı.
- **shadcn renk tabanı:** "neutral" seçildi. Faz 0.2 tasarımındaki zinc tonlarına çok yakın.
